01 — The problem

Ramp is paid in review round-trips.

  • The conventions already exist — scattered across docs, source patterns, tests, CI, and .ai/AGENTS.md.
  • A new engineer — human or agent — reassembles them by failing review.
  • The cost is senior-reviewer latency plus inconsistent first PRs. Not a missing tutorial.
The trap to avoid

A tool per SDLC step — that manufactures five sources of truth in a month.

02 — The one decision

Conventions become data.

One registry — conventions/rules.yaml — and every surface is generated from it. Edit one file; the agent's rules, the reviewer's checklist, the PM's Definition of Done, and CI cannot disagree.

And the unit is the change, not the rule — each rule carries an owner, so every role co-authors the same list.

03 — Architecture

Humans edit one file. Machines render the rest.

Live write lands on a fork of the library; the overlay attaches without rewriting upstream AGENTS.md / .ai/. On the fork the gate is file-scoped, and the default MCP is empty so Cloud launches never stall on OAuth.

Grok Bot on iPhone is the same read-side: paste generated profiles into the app. They translate gate output for a role — and never gate. Multiplicity of readers, one source of truth.

06 — Business value

Two levers a platform lead already reports.

Review round-trips / first PR ↓

The gate removes the mechanical bounce — moved import, missing mixin, empty test — before a senior ever looks.

Time-to-first-merge ↓

A correct scaffold from day one. First PRs fail on the paper, not on a missing SchedulerMixin.

Grounded, not guessed: the scheduler contract (set_timesteps / step) was verified against real source across three schedulers — not the stale philosophy doc that still says set_num_inference_steps.

07 — Live in the room

Kit first, then the fork.

  1. Catch the bad — the gate flags examples/candidate_scheduler by rule id, with fixes.
  2. Ground — read scheduling_ddpm.py / scheduling_euler_discrete.py: set_timesteps + step.
  3. Scaffold — /scaffold scheduler EulerLite; leave TODO(engineer) for the math.
  4. Green — file-scoped gate passes; make grokbot ROLE=qa. Never --all the library.

A runnable artifact, not slideware — the commands live in docs/LIVE_DEMO.md.

08 — Grok Bot on your phone

Same registry. Three Bots. Paste, don't provision from git.

Ramp Kit QA

Risk briefing. Owned: TEST001, TEST002. Paste Name / Title / Description from make grokbot-pack.

Ramp Kit PM

Status digest. Owned: DOC001. Same Cursor account as this kit. App Store app is Grok Bot, not Cursor for iOS.

Ramp Kit DevOps

Health signal. Owned: DEVICE001, LOG001, CUST001. Standing order: translate gate JSON — never gate, never merge.

The iPhone app has no create-from-git API. Profiles are generated from owner: tags. CLI briefing stays tools/grokbot_sim.py. Steps: docs/GROKBOT.md.

09 — Owned by the team, not by me

  • A new component (model, pipeline) = registry rows + a template. No new machinery.
  • Drift detection + contract re-verification keep it honest as the library evolves.
  • Grok Bot on iPhone: re-paste profiles after make build. Mechanical auto-fix later — never on numerics.

First PRs fail on the math — the reviewer's job — not on a missing SchedulerMixin.
