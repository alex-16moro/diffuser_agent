Solutions Architect technical screen · briefing

One registry. One gate. The whole team reads the same change.

A platform team ramps engineers onto a convention-heavy library and pays for it in review round-trips. This overlay does not replace Hugging Face’s .ai/. It turns scattered conventions into data, enforces them identically from editor to CI, and gives PM, QA, and DevOps a view of the same change.

Works offline. No network.

1. Problem

Engineering knowledge in huggingface/diffusers already exists: docs, source patterns, tests, CI, .ai/AGENTS.md, review rules. A new engineer (human or agent) reassembles it by failing review. Cost is senior latency plus inconsistent first PRs — not a missing tutorial.

The customer asked for the whole path a change takes, and for people around engineering to benefit too. The failure mode to avoid is a tool per SDLC step, which creates five sources of truth in a month.

2. Architecture

conventions/rules.yaml ← humans edit ONLY this │ id, owner, check, severity, DoD ├──────────────────────────────────► build_projections.py │ agent rules · AGENTS.md │ PM DoD · QA checklist · CI YAML │ GrokBot specs (read-side) └──────────────────────────────────► convention_check.py editor hook = pre-PR = CI exit code = blocking findings

The unit is the change, not the rule. Each rule has an owner (dev, architect, qa, pm, devops). Roles co-author one list. GrokBot agents translate gate JSON for a role; they never gate.

Live write lands on a fork of the library. Overlay attaches; it does not rewrite upstream AGENTS.md / .ai/. On the fork the gate is file-scoped. Default MCP is empty so Cloud launches do not prompt for OAuth.

4. Business value

Two levers a platform lead already reports: review round-trips per first PR and time-to-first-merge. The gate removes the mechanical bounce (moved import, missing mixin, empty test). QA spends judgment on the paper. PM sees the same Definition of Done CI will run. DevOps gets a cheap, GPU-less job plus drift and contract re-verify so the kit does not rot when the author is gone.
